🔧 QUICK SETUP (5 MIN)
────────────────────────────────────────────────────────────────────────────
1. Get API key
   → http://frigate.local:5000 → Settings → API Tokens
   → New Token, name: eagle-diagnostics, scopes: *:read

2. Test connectivity
   $ python test_frigate_agent.py \
       --frigate-url http://frigate.local:5000 \
       --frigate-api-key sk_xxxx...

3. Deploy MCP server
   OPTION A (Docker):
   $ docker compose -f compose.frigate.yaml up -d

   OPTION B (Standalone):
   $ python frigate_mcp_server.py \
       --frigate-url http://frigate.local:5000 \
       --frigate-api-key sk_xxxx...

4. Claude MCP config
   {
     "frigate": {
       "command": "python",
       "args": ["frigate_mcp_server.py", "--frigate-url", "http://frigate.local:5000", "--frigate-api-key", "sk_xxxx..."]
     }
   }

🚀 CAPTURE SNAPSHOT
────────────────────────────────────────────────────────────────────────────
Via Python:
  from frigate_diagnostic_agent import capture_snapshot
  result = await capture_snapshot(
    frigate_url="http://frigate.local:5000",
    frigate_api_key="sk_xxxx...",
    event_window_hours=24,
    metric_sample_seconds=120
  )

Via Claude (MCP):
  Tool: frigate/capture_snapshot(
    event_window_hours=24,
    metric_sample_seconds=120,
    include_media=false
  )

Returns:
  {
    health_status: { label: "PASS|DEGRADED|BLOCKED", summary, issues, timestamp },
    output_dir: "/eagleha/evidence/frigate",
    output_files: { summary, config, stats, events, logs },
    data_summary: { cameras, events_24h, detectors, warnings_errors }
  }

✅ HEALTH STATUS
────────────────────────────────────────────────────────────────────────────
PASS       All cameras healthy, all metrics good
DEGRADED   Issues detected (check summary for details)
  └─ Examples: Process uptime <95%, skipped frames, high CPU
BLOCKED    Cannot collect data (API/network issue)

🔐 SECURITY
────────────────────────────────────────────────────────────────────────────
✓ Read-only access (GET endpoints only)
✓ No config modification, event deletion, or camera control
✓ No MQTT, RTSP, or credential access
✓ Automatic secret sanitization (passwords, API keys redacted)
✓ Runs as non-root user in container
✓ Single constrained tool interface

⚠️ TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────
Connection refused?
  → Check Frigate is running: curl http://frigate.local:5000/api/version

401 Unauthorized?
  → Check API key scopes (events:read, config:read, stats:read)
  → Test: python test_frigate_agent.py --frigate-api-key sk_newkey

BLOCKED status?
  → Check logs: docker logs frigate-diagnostics (if Docker)
  → Or: tail -f /var/log/frigate-diagnostic.log (if standalone)

Output files empty?
  → Check disk space: df -h /eagleha
  → Check permissions: ls -la /eagleha/evidence/frigate

Full details: See FRIGATE_SETUP.md § Troubleshooting
